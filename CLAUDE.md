# Hinweise für Claude

- **Schweizer Rechtschreibung:** Nie „ß" verwenden, immer „ss" (z. B. „Verschleiss", „Grösse", „heiss"). Gilt für Dashboard, README und alle Texte im Repo.
- **Branch-Regel:** Nie direkt auf `main` ändern oder pushen. Änderungen immer auf einem eigenen Branch (z. B. dem der Sitzung) machen, pushen und erst nach Ansage des Nutzers in `main` mergen – immer als **Squash-Merge** (ein einzelner Commit auf `main`).
